# Stack and Queue Operations

This repository contains implementations and practice programs for **Stack** and **Queue** data structures using **C++**.

## Topics Covered

### Stack

* Push
* Pop
* Peek
* Display
* String Stack
* Palindrome Check
* Infix to Postfix
* Infix to Prefix
* Balanced Parentheses

### Queue

* Enqueue
* Dequeue
* Front
* Rear
* Display
* Circular Queue

## Language

* C++

## Purpose

This repository is for practicing and understanding the basic operations and applications of **Stacks and Queues**.
